# 전기 마스터 타운

초등 6학년 과학 '전기의 이용'(전자석 · 전기 효율과 안전)과 실과 '인공지능이 만들어지는 과정 체험'을 잇는 **AI 프로그램 개발 수업용 게임**입니다. 마인크래프트식 3D 블록 마을을 탐험하며 전자석과 전기 안전을 배우고, 코드를 쓰지 않고 AI의 판단 방법을 설계 · 학습 · 시험 · 개선합니다.

- 설치 없이 `index.html` 한 파일로 실행됩니다(오프라인 가능).
- 학생은 이름(또는 별명)과 비밀번호(숫자 4~8자리)만으로 로그인합니다. 같은 이름과 비밀번호로 들어오면 어느 기기에서든 기록이 이어집니다. 학급 서버(`server.js`)로 열면 기록이 서버에 학생별로 저장되고, 파일로 열면 그 기기에 학생별로 저장됩니다.

## 들어 있는 것

- **3D 블록 마을**: 이야기(점등식 D-5), 교과서 순서대로 이어지는 **활동 10개**(인물이 다음 사람을 알려 줌), 레벨·가방·길가 친구, 점프
- **교재 활동 미니 게임 7개**(각 3단계): 전자석 실험 게임, 전자석 탐정, 고철장 크레인 조종, 질문 미끄럼틀, 우리 집 안전 탐정, 로봇 훈련소, 전기 안전 캠페인
- **AI 두 가지**: 질문 길(의사결정트리)로 만드는 AI 크레인 두뇌, 예시 문장으로 가르치는 AI 안전 로봇(분류)
- **길 건너기 안전(❤️)** 과 **전기차 충전소 프로젝트**(시장님 설득 퀘스트)
- **맵 만들기**와 맵 코드 공유

수업 설계는 [전기마스터타운_수업기획서.md](전기마스터타운_수업기획서.md), 지도안은 [전기마스터타운_AI융합수업지도안.md](전기마스터타운_AI융합수업지도안.md)에 있습니다.

## 실행

```bash
npm start
```

그다음 http://localhost:3000 을 엽니다. 또는 `index.html`을 브라우저로 바로 열어도 됩니다(이때는 기기 안에만 저장).

| 환경 변수 | 뜻 |
|---|---|
| `DATA_DIR` | 학생 기록을 저장할 폴더 (기본 `./data`, Railway에서는 볼륨 경로) |
| `SECRET` | 로그인 표 서명용 비밀값 (없으면 `DATA_DIR`에 자동 생성) |

## 고치기

소스는 `전기마스터타운/src`에 조각으로 나뉘어 있고, 아래 명령으로 한 파일로 묶습니다.

```bash
npm run build
```

`index.html`과 `전기마스터타운.html`(같은 내용)이 새로 만들어집니다.
