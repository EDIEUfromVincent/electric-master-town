# 전기 마스터 타운

초등 6학년 과학 '전기의 이용'(전자석 · 전기 효율과 안전)과 실과 '인공지능이 만들어지는 과정 체험'을 잇는 **AI 프로그램 개발 수업용 게임**입니다. 마인크래프트식 3D 블록 마을을 탐험하며 전자석과 전기 안전을 배우고, 코드를 쓰지 않고 AI의 판단 방법을 설계 · 학습 · 시험 · 개선합니다.

- 설치 없이 `index.html` 한 파일로 실행됩니다(오프라인 가능).
- 진행 상황은 그 기기의 브라우저에 저장됩니다.

## 들어 있는 것

- **3D 블록 마을**: 이야기(점등식 D-5), 미션 7개, 레벨·가방·길가 친구
- **교재 활동 미니 게임 7개**(각 3단계): 전자석 실험 게임, 전자석 탐정, 고철장 크레인 조종, 질문 미끄럼틀, 우리 집 안전 탐정, 로봇 훈련소, 전기 안전 캠페인
- **AI 두 가지**: 질문 길(의사결정트리)로 만드는 AI 크레인 두뇌, 예시 문장으로 가르치는 AI 안전 로봇(분류)
- **길 건너기 안전(❤️)** 과 **전기차 충전소 프로젝트**(시장님 설득 퀘스트)
- **맵 만들기**와 맵 코드 공유

수업 설계는 [전기마스터타운_수업기획서.md](전기마스터타운_수업기획서.md)에 있습니다.

## 실행

```bash
npm start
```

그다음 http://localhost:3000 을 엽니다. 또는 `index.html`을 브라우저로 바로 열어도 됩니다.

## 고치기

소스는 `전기마스터타운/src`에 조각으로 나뉘어 있고, 아래 명령으로 한 파일로 묶습니다.

```bash
npm run build
```

`index.html`과 `전기마스터타운.html`(같은 내용)이 새로 만들어집니다.
